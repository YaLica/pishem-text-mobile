Тексttура — оформление Gloss

В папке upload-to-github три файла:
index.html — обновлённый заголовок, компактный логотип и подключение оформления;
texttura-gloss.css — оформление кнопок, панели и полей;
texttura-icon.png — ваш исходный логотип с чернильницей и tt.

КАК УСТАНОВИТЬ
1. Распакуйте ZIP на компьютере.
2. Откройте github.com/YaLica/pishem-text-mobile, ветку main и корень репозитория.
3. Нажмите Add file → Upload files.
4. Откройте папку upload-to-github и перетащите именно ТРИ ФАЙЛА из неё, не саму папку.
5. Сохраните Commit changes с сообщением «Оформление Gloss и название Тексttура».
6. Дождитесь успешного обновления GitHub Pages и обновите редактор Ctrl+Shift+R.
7. Проверьте вид на компьютере и телефоне: раскрытие панелей, текст, картинки, плашки, эмодзи, список шрифтов и экспорт.

Timeweb и бэкенд не обновляйте. Все скрипты, API, поведение и порядок элементов сохранены.
Цвет рабочего стола, холст и содержимое постов не изменены.
Списки шрифтов сохраняют начертания примеров.

ВОЗВРАТ
В backup/index.html находится исходный индекс из присланного архива.
Для возврата загрузите его в корень репозитория вместо нового index.html.
Новые CSS и PNG перестанут подключаться.
Не загружайте папку backup на сайт.

ПРОВЕРКИ
Сравнены все исходные файлы: изменён только index.html, добавлены CSS и PNG.
Все JavaScript-файлы, обработчики, идентификаторы и разметка рабочего стола совпадают с оригиналом.
Проверены парность скобок CSS и отсутствие правил геометрии; правила скрытия, расположения и анимации не добавлялись.
Браузерный предпросмотр в среде подготовки недоступен; визуальная проверка после загрузки на GitHub Pages обязательна.
